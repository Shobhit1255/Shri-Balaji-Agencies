# Shri Balaji Agencies Website

## Files
- index.html — website structure
- style.css — responsive design and animations
- script.js — product data, search, category filters, modals and WhatsApp enquiry

## Run
Open `index.html` in a browser.

## Before publishing
1. Replace `+91 99999 99999` in `index.html` with the shop's real phone number.
2. Replace `919999999999` in `script.js` with the shop's WhatsApp number.
3. Replace the shop address.
4. Replace emoji product visuals with real product images.
5. Add actual brands, prices/specifications and more products in the `products` array.

## Next upgrade
For a truly database-driven version, add Node.js + Express + MongoDB and an admin dashboard so products can be added/edited without changing code.
